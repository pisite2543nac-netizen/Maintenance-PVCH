# Computer Care

เว็บไซต์ระบบตรวจสอบและบำรุงรักษาคอมพิวเตอร์เบื้องต้น สำหรับนักเรียนระดับ ปวช.

## วิธีใช้งาน
1. เปิด `index.html` ในเว็บเบราว์เซอร์ หรือเผยแพร่ด้วย GitHub Pages
2. กรอกข้อมูลผู้รับผิดชอบและรหัสเครื่อง
3. ทำรายการตรวจสอบและบันทึกผลก่อน/หลังบำรุงรักษา
4. เปิดเมนูรายงาน แล้วเลือกพิมพ์ / Save as PDF เพื่อบันทึกเอกสาร A4

## เผยแพร่ด้วย GitHub Pages
1. สร้าง GitHub repository ใหม่
2. อัปโหลดไฟล์ `index.html` ไปไว้ที่ root ของ repository
3. ไปที่ Settings > Pages
4. เลือก Deploy from a branch
5. เลือก branch `main` และ folder `/ (root)` แล้วกด Save

## หมายเหตุ
- รุ่นนี้เป็นเว็บแบบ Static ไม่ต้องติดตั้ง Node.js หรือฐานข้อมูล
- ประวัติการตรวจสอบเก็บใน LocalStorage ของเบราว์เซอร์และอุปกรณ์ที่ใช้
- ยังไม่ได้เชื่อม Supabase หรือระบบบัญชีผู้ใช้
- การจับเวลาเป็นตัวช่วยบันทึกเวลา ผู้ใช้งานต้องกดเริ่ม/หยุดตามการทดสอบจริง
