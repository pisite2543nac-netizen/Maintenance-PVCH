เริ่มต้นใช้งาน

1. อ่านคู่มือความรู้ก่อนลงมือปฏิบัติ 2. กรอกข้อมูลผู้รับผิดชอบและเครื่อง 3. ตรวจสอบสถานะก่อนทำ 4. บำรุงรักษาตามความเหมาะสม 5. ตรวจซ้ำและบันทึกผลหลังทำ 6. พิมพ์รายงาน A4

ข้อควรระวังด้านความปลอดภัย

  • ปิดเครื่องและถอดปลั๊กก่อนทำความสะอาดภายในเคส
  • ห้ามเปิด Power Supply หรือแกะอุปกรณ์ที่มีไฟฟ้าแรงดันสูง
  • ไม่ลบไฟล์ระบบหรือไฟล์ที่ไม่ทราบแหล่งที่มา
  • ขออนุญาตครู/ผู้ดูแลก่อนเปลี่ยนแปลง BIOS ติดตั้งโปรแกรม หรือเปิดเคส
  • สำรองข้อมูลก่อนดำเนินการที่มีความเสี่ยง

คู่มือความรู้การดูแลคอมพิวเตอร์เบื้องต้น

สำหรับนักเรียนระดับประกาศนียบัตรวิชาชีพ (ปวช.) อ่านและปฏิบัติตามขั้นตอนอย่างปลอดภัย

1. รู้จักส่วนประกอบคอมพิวเตอร์

CPU ประมวลผลคำสั่ง, RAM หน่วยความจำชั่วคราว, Mainboard แผงวงจรหลัก, SSD/HDD จัดเก็บข้อมูล, Power Supply จ่ายไฟ และอุปกรณ์ต่อพ่วง เช่น จอภาพ เมาส์ คีย์บอร์ด ลำโพง

2. การทำความสะอาดเครื่อง

  1. ปิดเครื่อง ถอดปลั๊ก และรอให้เครื่องหยุดทำงาน
  2. เช็ดภายนอกด้วยผ้าไมโครไฟเบอร์แห้ง
  3. ใช้ลมเป่าฝุ่นอย่างเหมาะสม โดยยึดใบพัดไม่ให้หมุนเร็วเกินไป
  4. หลีกเลี่ยงการฉีดน้ำยาลงอุปกรณ์โดยตรง
  5. หากไม่ชำนาญ ให้ทำเฉพาะภายนอกและแจ้งครูผู้ดูแล

3. จัดการไฟล์ขยะอย่างปลอดภัย

  1. เปิด Settings → System → Storage → Temporary files
  2. ตรวจสอบรายการที่ระบบแนะนำก่อนเลือก
  3. ลบเฉพาะไฟล์ชั่วคราวที่เข้าใจ หลีกเลี่ยง Downloads หากยังไม่ได้สำรอง
  4. ตรวจสอบ Recycle Bin ก่อนล้าง
  5. ใช้ Storage Sense ตามนโยบายของห้องปฏิบัติการ

4. ทำให้คอมพิวเตอร์ทำงานคล่องขึ้น

  • ปิดโปรแกรมที่ไม่ใช้งาน
  • ตรวจสอบ Task Manager → Processes เพื่อดู CPU, Memory และ Disk
  • ตรวจ Startup Apps และปิดเฉพาะโปรแกรมที่ไม่จำเป็น
  • เหลือพื้นที่ว่างในไดรฟ์ระบบให้เพียงพอ
  • รีสตาร์ตเครื่องหลังติดตั้งอัปเดตเมื่อได้รับอนุญาต

5. ตรวจสอบอินเทอร์เน็ต

  1. ตรวจสาย LAN หรือสถานะ Wi-Fi
  2. เปิด Command Prompt แล้วใช้ ipconfig ตรวจ IP
  3. ใช้ ping 8.8.8.8 ทดสอบการเชื่อมต่อ
  4. ใช้ ping google.com ตรวจการทำงานของ DNS
  5. หากเชื่อมต่อไม่ได้ ให้บันทึกข้อความผิดพลาดและแจ้งผู้ดูแลเครือข่าย

6. ความปลอดภัยและไวรัส

  • เปิด Windows Security และตรวจสถานะ Virus & threat protection
  • อัปเดตฐานข้อมูลไวรัสตามสิทธิ์ที่ได้รับ
  • ไม่เสียบ USB ที่ไม่ทราบแหล่งที่มา
  • ไม่ติดตั้งโปรแกรมเถื่อนหรือโปรแกรมที่ไม่ผ่านการอนุมัติ

7. อาการเสียที่พบบ่อย

อาการแนวทางตรวจสอบเบื้องต้น
เปิดเครื่องไม่ติดตรวจปลั๊ก สายไฟ สวิตช์ และแจ้งผู้ดูแล
จอไม่แสดงภาพตรวจสายจอ แหล่งสัญญาณ และไฟสถานะ
เครื่องช้าตรวจ Task Manager พื้นที่ดิสก์ และ Startup
ไม่มีเสียงตรวจระดับเสียง Output device และสายลำโพง
อินเทอร์เน็ตไม่ได้ตรวจ LAN/Wi-Fi, IP และ ping
เครื่องร้อน/เสียงดังตรวจช่องระบายอากาศและฝุ่น หากผิดปกติให้หยุดใช้งาน

8. การตรวจสอบหลังบำรุงรักษา

ทดสอบเปิดเครื่อง เข้าสู่ระบบ ตรวจจอภาพ เสียง เครือข่าย โปรแกรมพื้นฐาน และอุปกรณ์ต่อพ่วง เปรียบเทียบผลกับก่อนทำ พร้อมบันทึกสิ่งที่ยังแก้ไขไม่ได้
